## Executive verdict

WizJobs should **not** try to beat Bayt or LinkedIn on volume. The winning wedge is:

> **Dubai creative-tech hiring where portfolio evidence, craft taxonomy, commute/visa transparency, and recruiter responsiveness matter more than résumé keywords.**

The candidate app + planned employer site should form a **trusted two-sided marketplace**, not a generic career OS with a map skin. Map, match %, and Wizy only become a moat if they improve **qualified matches and hires**—not screen time.

**Key UAE insight:** No leading Dubai incumbent appears to own **map-first discovery + portfolio-first creative-tech hiring**. Trust (ghost jobs, scams, silence after apply) is a category-wide pain.

|---|---|---|
| Scale + search | Indeed | Avoid undifferentiated infinite feed |

## What “best” should mean for WizJobs

**North star:** qualified-hire outcomes, not MAU or chatbot sessions.

> % of shortlists → mutual interview/work sample → accepted offer or paid engagement

Track four scorecards: candidate value, employer value, marketplace liquidity, trust/AI quality.

Suggested internal gates (after 90-day baseline):  
≥70% roles with salary/work mode/location/SLA · ≥90% verified/fresh · ≥50% wedge roles get 3 qualified candidates in 7 days · ≤14 days to first qualified shortlist · strong repeat usage on both sides.

## How to be best — prioritized bets

### 1) Own the creative-tech proof profile (candidate + employer)
- Work before résumé: hero project, reel/turntable, tools, contribution, shipped status.
- Structured craft taxonomy (tech art, Unreal version, Niagara, viz, XR — not “3D designer”).
- Claimed vs demonstrated vs verified skills.
- Import Behance / ArtStation / Dribbble / GitHub / showreel.

### 2) Make discovery curated + transparent (not a dashboard wall)
- Default card: salary, work mode, area, commute, visa, freshness, employer verified, response SLA.
- **Daily curated set** (Otta-style) over infinite feed.
- Map as decision tool: commute-time isochrones, clusters (DIFC / Media City / D3 / Business Bay), list↔map sync. Drop map theater if it doesn’t lift qualified actions.

### 3) Explain every match — or don’t show a %
Industry research treats **explainable person–job matching as unsolved**. Opaque “96%” is clone behavior.
Every match needs: matched because · strengths · gaps · deal-breakers · why now · more/less like this.

### 4) Trust is the UAE wedge
Ghost-job estimates in industry sources often land ~20–30%+ of postings. Bayt publishes scam guidance for a reason.  
Productize: verified employers/recruiters, freshness, salary disclosure, response-time badges, application status truth, anti-unpaid-spec work, fraud report.

### 5) Wizy as outcome copilot — not interview mascot
**Trust-building:** fit explanation, missing evidence, portfolio narrative, interview prep, salary/commute tradeoffs, human-approved employer outreach drafts.  
**Gimmicky:** endless chat, auto-apply spam, fabricated experience, hidden paid placement as “AI match.”  
Measure edit/accept rates and interview uplift — not session length.

### 6) Employer website MVP (planned)
Table stakes: structured brief, verification, pipeline, messaging, status.  
Differentiators:
- Brief builder that forces salary / visa / portfolio asks / response SLA / rejects contradictory reqs  
- Portfolio-first shortlist + side-by-side craft compare  
- Creative audition: paid, time-boxed work samples with rubric (no unpaid production)  
- Responsiveness as ranking signal  
- Later: contracts/payments/compliance (YunoJuno-class) once liquidity exists  

Commercial wedge: transparent AED pricing below LinkedIn Recruiter; free/low entry posts + paid qualified reach — familiar Bayt/Naukrigulf pattern with specialist value.

### 7) Sequencing (avoid empty marketplace)
**90 days:** pick 2–3 role clusters + 2–3 Dubai geographies; concierge seed both sides; list-strong before map-rich; AI v1 on both sides with moderation.  
**6 months:** expand adjacent clusters only after repeat hires; multimodal portfolio analysis; local salary/response index; success-based pricing only after proving qualified shortlists.

## Implications for the current prototype (before UI fixes)

Aligned with the earlier UX critique:

| Current risk | Research says |
|---|---|
| Home as options wall | Leaders curate one next action / daily set |
| Opaque 96% match | Explain or remove |
| CV/skills mismatch vs Unreal roles | Craft taxonomy + evidenced projects |
| Dark login / generic SaaS home | Brand must feel creative-tech Dubai, not career OS clone |
| Apply one-click hollow | Need “what you send,” employer SLA, next steps |
| Map without density | Seed inventory first; map only where it aids commute/fit |
| Wizy as “Interview coach” everywhere | Mode-aware coaching tied to outcomes |
| No employer site yet | Design candidate trust loops that employers will later staff |

---

## Principal risks

1. **Cold start / empty map** — seed pods; never show pretty map with junk inventory.  
2. **Map novelty without hiring value** — A/B vs list; kill if no lift.  
3. **AI bias / hallucination** — evidence retrieval, confirmation, audit, appeal.  
4. **Portfolio plagiarism / AI-generated work** — provenance + live walkthroughs.  
5. **Chicken-and-egg** — concierge matching before self-serve scale.  
6. **Trying to be LinkedIn** — volume strategy loses to incumbents.
